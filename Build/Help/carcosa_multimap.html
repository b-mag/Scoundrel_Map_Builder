Carcosa — Multi-map WAD tutorial

Carcosa maps are authored in Doom Builder 64 Enhanced. Day-to-day work uses one multi-map WAD (for the showcase: carcosa.wad with MAP01–MAP04). Save Map is the build step — you do not need Gradle for normal editing.

1. Open the Carcosa megawad

  1. File → Open Map.
  2. Select scoundrel/assets/maps/carcosa.wad (or your own multi-map PWAD).
  3. Choose game configuration Carcosa (Doom 64) (selected by default).
  4. Pick a map marker: MAP01 Pallid Shoals, MAP02 Yhtill, MAP03 Demhe, MAP04 Ash Diadem.

2. Switch biomes

Only one map is open at a time. To edit another biome: File → Open Map again on the same WAD and pick a different MAP##. Save first if prompted.

3. Place an NPC and edit Lua

  1. Things mode → place a Carcosa thing (for example Enkai).
  2. Edit the thing → Script / RPG group for extras.
  3. Edit Lua for this thing opens the map CARCLUA lump and jumps to (or inserts) an on_use stub.

Scripts are map-level: one CARCLUA per map. Things are addressed by runtime id / thing_type.

4. Atmosphere and zones

  1. Select one or more sectors → Sector Edit → Carcosa atmosphere.
  2. Set weather / fog / outdoors / place name as needed.
  3. Zone assigns a shared rain policy (multi-select applies the same zone to many outdoor sectors). Day/night is pack / world script owned — do not reset sky_clock in every map script.

5. Script Editor lumps

  • CARCLUA — per-map events (on_load, on_use, on_kill, …).
  • CARCWLD — optional world script (prefer on MAP01) for planet clock and global quest watches. The Scoundrel pack also ships data/world.lua.

6. Cross-map quests (flags)

Flags, counters, items, world time, NPC roster, and zone rolls survive region hops. Map scripts talk through carcosa.flag / set_flag. 

-- MAP04 (boss map)
function on_kill(id, thing_type)
  if thing_type == 9204 then
    carcosa.set_flag("aldon_slain")
  end
end

-- MAP01 (hub)
function on_load()
  if carcosa.flag("aldon_slain") then
    carcosa.open_tag(7)  -- linedef Tag = 7 on the door
  end
end

Set the door linedef Tag in Linedef Edit to match open_tag(n).

7. Create a basic multi-map game WAD from scratch

  1. File → New Map. Name the lump MAP01. Draw a room, place a player start.
  2. File → Save Map → e.g. mygame.wad.
  3. File → New Map. Name the lump MAP02. Build the second area.
  4. File → Save Map Into… → choose the same mygame.wad. Builder appends MAP02 and keeps MAP01.
  5. Repeat for MAP03, MAP04, …
  6. Add CARCLUA / Carcosa atmosphere / NPCs on each map as needed.

In the Scoundrel pack, list regions in pack.json against that file with "map": "maps/mygame.wad" and "mapName": "MAP01" (etc.). See the engine docs under scoundrel/docs/carcosa/.

8. Optional: pack separate biome files

If you keep solo files (carcosa_shoals.mapwad, …) for focused work:

  • Tools → Pack maps into WAD… — pick sources, assign MAP##, optional world .lua as CARCWLD on the first map, write the megawad.
  • Command line (CI / recovery): from the Scoundrel repo, gradlew :game:mergeCarcosaWad.

Neither is required when you edit carcosa.wad (or your megawad) directly and Save.

9. Playtest

Save the map, then run the Carcosa desktop build (Scoundrel lwjgl3) with the pack that points at your WAD. Builder Test Map still expects a classic Doom EXE; Carcosa launch from Test Map is not wired yet.

Do not

  • Run :game:exportCarcosaMaps after hand-editing — it overwrites Builder work with Kotlin seeds.
  • Merge all biomes into one giant MAP## mesh — stay streamed (one map loaded at a time).
